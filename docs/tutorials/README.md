# Tutorials

Learning-oriented, step-by-step paths that are guaranteed to work if
followed.

- [Your first Kolsch agent](first-agent.md) — define an agent in YAML,
  run it, inspect events, resume, stream, rebuild the DB from the log,
  serve over HTTP. ~10 minutes, no API key.
- [Write a card-emitting tool](write-a-card-tool.md) — build a tool
  whose output renders as a rich chat card.

To compose agents and Python steps into a multi-step workflow, see the
[Build a workflow](../how-to/build-a-workflow.md) how-to.
