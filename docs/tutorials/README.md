# Tutorials

Learning-oriented, step-by-step paths that are guaranteed to work if
followed.

- [Your first Kolsch agent](first-agent.md) — define an agent in
  YAML, run it, then resume and replay the session from its JSONL
  log. ~15 minutes, no API key required.
- [Write a card-emitting tool](write-a-card-tool.md) — build a tool
  whose output renders as a rich chat card. Assumes you've already
  read [Write a tool](../how-to/write-a-tool.md).

To compose agents and Python steps into a multi-step workflow, see the
[Build a workflow](../how-to/build-a-workflow.md) how-to.
