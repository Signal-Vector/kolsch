# Contributing to Kolsch

This file is a directory, not a manual. The detailed conventions live
in [`docs/`](docs/index.md). Start here, follow the links.

---

## Conventions

- **In-code documentation** — docstrings, module headers, and inline
  comments: see
  [`docs/process/documentation-conventions.md`](docs/process/documentation-conventions.md).
  Google style, MkDocs-ready.

- **Development workflow and hard rules** — type hints, error model,
  event-sourced ground truth, the dev/test container flow, pre-commit
  gate: see [`AGENTS.md`](AGENTS.md). Written for AI agents working on
  the codebase; humans should read it too.

- **Project overview and getting started** — see
  [`README.md`](README.md).

- **Documentation tree** — Diátaxis-structured under
  [`docs/`](docs/index.md). The Master Index gives a recommended
  reading order.

---

## What isn't written down yet

Conventions for **spec / process files**, **PR templates**, and
**MkDocs build configuration** are not yet captured. They'll land as
their own files in `docs/process/` as the conventions get pinned down.
If you find yourself wishing one of them existed, open an issue or PR.
